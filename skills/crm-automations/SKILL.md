# Automations

- `automations_list`: List all automations
- `automations_catalogue`: What an automation can be built from
- `automations_recipes`: Ready-made sequences
- `automations_get_run_detail`: Get run detail with per-action logs
- `automations_settle_run`: Mark a run as dealt with
- `automations_get_by_id`: Get automation with actions
- `automations_delete`: Delete automation
- `automations_enrol`: Put people through it by hand
- `automations_numbers`: What each step came to
- `automations_list_runs`: List execution history for an automation
- `automations_open_webhook`: Open an automation's webhook trigger
- `webhook_trigger_update`: Change an automation's webhook trigger
