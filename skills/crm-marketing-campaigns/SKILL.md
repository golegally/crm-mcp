# Marketing campaigns

- `campaigns_list`: List campaigns
- `campaigns_create`: Add a campaign
- `campaigns_get`: Get a campaign
- `campaigns_edit`: Change a campaign
- `campaigns_remove`: Delete a campaign
- `campaigns_save_outreach`: Set an outreach campaign's message
- `campaigns_audience`: Count who an outreach campaign reaches
- `campaigns_send`: Send an outreach campaign
- `campaigns_people`: List a campaign's leads and sales
- `campaigns_sends`: List an outreach campaign's messages
