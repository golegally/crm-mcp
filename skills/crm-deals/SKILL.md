# Deals

- `deals_list`: List deals with pagination and search
- `deals_create`: Create a deal
- `deals_pipeline_summary`: Get pipeline summary (every stage, with its deal count and value)
- `deal_files_list`: List a deal's files
- `deal_files_add`: Add an uploaded file to a deal
- `deal_files_start_upload`: Start a file upload to a deal
- `deal_files_delete`: Delete a deal's file
- `deal_files_download`: Download a deal's file
- `deals_get_by_id`: Get a deal by ID
- `deals_edit`: Edit a deal
- `deals_delete`: Delete a deal
