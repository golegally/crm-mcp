# Segments

- `segments_score_rules`: Lead score rules
- `segments_add_score_rule`: Add a score rule
- `segments_save_score_rule`: Change a score rule
- `segments_delete_score_rule`: Remove a score rule
- `segments_list`: Saved segments
- `segments_create`: Save a segment
- `segments_fields`: What a segment can test
- `segments_preview`: How many a draft matches now
- `segments_get`: One segment
- `segments_update`: Change a segment
- `segments_delete`: Delete a segment
- `segments_members`: Who is in it, latest first
- `segments_report`: What its members add up to
