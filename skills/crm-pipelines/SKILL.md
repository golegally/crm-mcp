# Pipelines

- `pipelines_list`: List all active pipelines
- `pipelines_create`: Create a pipeline with optional stages
- `pipelines_get_by_id`: Get pipeline with stages
- `pipelines_edit`: Edit pipeline metadata
- `pipelines_archive`: Archive a pipeline (soft-delete)
- `pipelines_add_stage`: Add a stage to a pipeline
- `pipelines_reorder_stages`: Reorder every stage of a pipeline in one request
- `pipelines_edit_stage`: Edit one stage of a pipeline
- `pipelines_remove_stage`: Remove a stage that holds no deals
