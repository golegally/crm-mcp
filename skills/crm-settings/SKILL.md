# Settings

- `team_alerts_get`: Team alerts and the marketing summary
- `team_alerts_put`: Set team alerts and the marketing summary
- `organization_settings_business_hours`: When this organization may send marketing messages
- `organization_settings_set_business_hours`: Set when this organization may send marketing messages
- `organization_settings_message_limits`: Limits on automated messages, across every channel
- `organization_settings_set_message_limits`: Set the limits on automated messages
