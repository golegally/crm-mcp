# Tags

- `tags_list`: List all tags
- `tags_create`: Create a tag
- `tags_tag_entity`: Tag an entity (contact/deal/company)
- `tags_list_entity_tags`: List tags for a specific entity
- `tags_edit`: Edit a tag
- `tags_delete`: Delete a tag
- `tags_untag_entity`: Remove a tag from an entity
